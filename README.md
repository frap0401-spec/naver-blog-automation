# 드롭컷 · 쇼핑쇼츠 편집 에이전트

상품 원본 영상을 올리면 **컷편집 · 자막 · 나레이션 · 카피라이팅 · 제목 · 쿠팡파트너스 링크 문구**까지
한 번에 만들어 주는 쇼핑쇼츠(유튜브 쇼츠/릴스/네이버 클립) 자동 편집기입니다.

사용자가 하는 일은 다섯 번의 클릭뿐입니다.

| 단계 | 하는 일 | 자동으로 처리되는 것 |
|---|---|---|
| 1. 올리기 | 상품 영상(여러 개 가능) + 상품명·쿠팡 링크(선택) | 장면 추출 → Claude가 상품 분석 |
| 2. 원고 고르기 | 스타일이 다른 원고 3개 중 선택(문장·제목 수정 가능) | 후킹 제목, 나레이션, 문장별 컷 계획, 영상 제목, 설명, 해시태그 |
| 3. 목소리 고르기 | 목소리 3종 미리 듣고 선택, 말 속도·배경음악 | — |
| 4. 만들기 | 클릭 | 문장별 TTS → 음성 길이에 맞춰 컷 편집 → 9:16 변환 → 자막·상단 제목 합성 |
| 5. 내보내기 | mp4 저장, 제목·설명·고정댓글 복사 | 쿠팡 파트너스 대가성 문구 자동 포함 |

## 원고 모드 두 가지

1단계에서 고릅니다.

| 모드 | 비용 | 하는 일 |
|---|---|---|
| **AI 자동 원고** | Claude API 사용료(쇼츠 1편 수백 원 수준) | 영상을 보고 원고 3개 + 문장별 장면까지 자동 |
| **원고 직접 입력** | 무료 | 내가 쓴 원고로 컷편집·자막·나레이션·제목·쿠팡 문구 자동. 장면은 영상 순서대로 자동 배치되고 2단계에서 문장별로 바꿀 수 있음 |

직접 입력할 때는 **[claude.ai용 요청문 복사]** 버튼을 눌러 claude.ai 채팅에 붙여넣고, 나온 답을 그대로 원고 칸에 붙여넣으면 됩니다.
원고 형식:

```
상단1: 이거 모르면 손해          ← 화면 위 고정 제목(흰색)
상단2: 강아지 급수기 끝판왕      ← 둘째 줄(노란색)
제목: 물 갈아주기 귀찮은 집사 필수템
설명: 매일 물 갈아주기 힘드셨죠?
해시태그: 강아지, 반려견용품, 자동급수기
고정댓글: 제품 정보는 아래 링크에서 확인하세요!
---
아직도 물그릇 하루에 몇 번씩 갈아주세요?
이거 하나 놓고 나서 완전히 편해졌어요.
```

`상단1:` 같은 항목은 빼도 되고, 나레이션은 한 줄에 한 문장씩 적습니다.
API 키가 없으면 화면이 자동으로 '원고 직접 입력'으로 선택됩니다.

## 설치

1. **Python 3.10 이상** 설치
2. (AI 자동 원고를 쓸 때만) **Claude API 키** 준비 → `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY` 입력.
   비용을 줄이려면 `.env`에 `DROPCUT_MODEL=claude-sonnet-5-5`를 추가하세요.
3. 실행
   - Windows: `run.bat` 더블클릭
   - Mac/Linux: `./run.sh`

처음 실행할 때 필요한 패키지를 자동 설치하고 브라우저에서 `http://127.0.0.1:8000`을 엽니다.
ffmpeg는 PATH에 있으면 그것을, 없으면 `imageio-ffmpeg`에 포함된 것을 씁니다.

## 자동 모드 (클릭 없이 한 번에)

```bash
./run.sh make 영상1.mp4 영상2.mp4 --name "강아지 자동 급수기" --link "https://link.coupang.com/a/xxxx"
# 원고를 직접 쓸 때(무료): --script-file 원고.txt
# 옵션: --script 2 (원고 번호) --voice ko-KR-InJoonNeural --rate 15 --bgm bgm.mp3 --out output
```

`output/` 폴더에 `shorts.mp4`, `upload.txt`(제목·설명·고정댓글·원고), `subtitles.srt`가 저장됩니다.

## 꾸미기

- **글꼴**: `assets/fonts/`에 굵은 한글 글꼴(예: Pretendard Black, G마켓 산스 Bold)을 넣고
  `.env`에 `DROPCUT_FONT=글꼴 이름`을 적으면 자막·제목에 적용됩니다. 기본값은 Windows `Malgun Gothic`, Mac `Apple SD Gothic Neo`.
- **배경음악**: 저작권 걱정 없는 음원을 `assets/bgm/`에 넣으면 3단계에서 고를 수 있습니다.
- **목소리**: Microsoft Edge 무료 TTS(선희·인준·현수)를 사용하며 인터넷 연결이 필요합니다.

## 구조

```
dropcut/
  server.py     웹 API (FastAPI)
  pipeline.py   5단계 작업 흐름, 결과물·업로드 문구 생성
  manual.py     원고 직접 입력 해석 + 장면 자동 배치
  llm.py        Claude 영상 분석 + 원고 3종 + 컷 계획 (구조화 출력)
  media.py      ffmpeg: 프레임 추출, 9:16 컷 생성(가로 영상은 흐린 배경), 합치기, 최종 렌더
  subtitles.py  상단 고정 제목(흰색/노란색) + 팝 효과 자막(ASS), SRT
  tts.py        나레이션 음성 합성
  static/       웹 화면
```

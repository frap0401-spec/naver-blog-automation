# 드롭컷 · 쇼핑쇼츠 편집 에이전트

상품 원본 영상을 올리면 **컷편집 · 자막 · 나레이션 · 카피라이팅 · 제목 · 쿠팡파트너스 링크 문구**까지
한 번에 만들어 주는 쇼핑쇼츠(유튜브 쇼츠/릴스/네이버 클립) 자동 편집기입니다.

## 세 가지 만들기 방식 (홈 화면 위쪽 탭)

| 탭 | 넣는 것 | 하는 일 |
|---|---|---|
| **컷·자막 자동 편집** | 직접 찍은 말하는 영상 | 말 없는 부분·군말(음, 어)을 잘라내고 받아쓴 말을 자막으로 붙임. 편집 화면 타임라인에서 구간을 넣고 빼거나 끝을 끌어 조절 |
| **영상·사진으로 자동 제작** | 제품 영상·사진 여러 개 | Claude가 원고를 쓰고 AI 목소리로 읽어 문장마다 장면을 붙임 |
| **상세페이지로 만들기** | 쇼핑몰 상세페이지 이미지(길게 캡처한 것도 됨) | 이미지를 화면 크기로 잘라 장면으로 쓰고, Claude가 이미지 속 글을 읽어 원고 작성 |

## 사용 흐름 (자동 제작·상세페이지)

1. **넣기** — 썸네일의 ✕로 뺄 수 있음
2. **원고** — [✦ 영상 보고 원고·업로드 글 쓰기]: 길이(15/30/45초)·추가 요청 → 상품 분석(누가/언제/왜), **원고 3안 × 썸네일 문구 3개**,
   제목 후보, 설명글, 답글, DM 문구, 검색어. API 키가 없으면 원고 칸에 직접 쓰거나 [claude.ai용 요청문 복사]
3. **목소리**(★ 즐겨찾기, 미리 듣기, 빠르기) · **화면 비율** · **그래픽**(테마·위치·양) · **효과음** · **얼굴 보정** · **스타일** · 제목 · 쿠팡 링크
4. **만들기** — 목소리 → 영상 살펴보기 → 장면·그래픽 고르기(Claude) → 이어 붙이기 → 자막·문구 → 미리보기
5. **편집 화면** — 탭: 장면 / 자막·문구 / 그래픽 / 효과음 / 글자 가리기 / 얼굴 보정 / 업로드 글, 아래쪽 **타임라인**(그래픽·자막·영상·효과음 트랙, 누르면 그 장면으로 이동, 확대/축소)
6. **내 프로젝트** — 만든 영상이 모두 남아 다시 열어 고칠 수 있음

## 그래픽 · 효과음 · 얼굴 보정

- **그래픽**: 포인트 카드 / 체크리스트 / 전·후 비교 / 큰 숫자·단어. 테마(기본·강한 장면·글래스 UI), 위치(아래·가운데·화면 전체), 양(없음~많이).
  Claude가 설명이 필요한 문장을 골라 넣고, 편집 화면에서 문장마다 바꿀 수 있음 (API 키가 없으면 문장 위치만 골라 포인트 카드로 넣음)
- **효과음**: 휙·뿅·띵·딸깍·두둥 기본 제공, `assets/sfx/`에 넣은 파일도 사용. 장면 바뀔 때·그래픽 나올 때 자동, 문장마다 따로 지정 가능
- **얼굴 보정**: 피부 결을 부드럽게 하고 살짝 밝게 (얼굴을 따로 찾지 않고 화면 전체에 적용)
- **받아쓰기**: 컷·자막 자동 편집은 faster-whisper로 컴퓨터 안에서 받아씀. 처음 쓸 때 모델(small, 약 500MB)을 내려받음.
  더 정확하게: `.env`에 `DROPCUT_WHISPER=medium`

## 원본 자막·워터마크 지우기

편집 화면의 '글자 가리기' 탭에서 영상마다 설정합니다. AI 자동 원고 모드에서는 AI가 찾은 영역이 미리 채워집니다.

| 방법 | 언제 |
|---|---|
| 잘라내기 | 화면 아래/위 가로 띠 자막. 그 띠를 잘라내고 나머지로 화면을 채워 가장 깔끔 |
| 흐리게 | 가운데에 있는 글자 등 잘라낼 수 없는 곳 |
| 주변색으로 지우기 | 작은 로고·워터마크 |

원본 화면에서 드래그로 영역을 감싸거나 [아래 자막]·[위 글자]·[오른쪽 위 로고] 버튼을 누르면 오른쪽에 결과가 바로 보입니다.

## 어색한 컷 자동 보정 (기본 켜짐)

만들기 전에 원본 영상을 훑어 **검은 화면 · 멈춘 화면 · 컷 시작/끝에 순간적으로 끼는 장면 전환**을 찾습니다.
문장 구간이 이런 곳에 걸리면 가장 가까운 자연스러운 구간으로 옮기고, 문제없는 컷은 원래 위치 그대로 씁니다.
무엇을 고쳤는지는 편집 화면에 표시됩니다. 홈 화면에서 끌 수 있습니다(`make` 명령은 `--no-smart-cut`).

## 목소리

- **기본(무료)**: 선희·인준·현수 3명을 톤별로 나눈 8가지
- **ElevenLabs(선택, 유료)**: `.env`에 `ELEVENLABS_API_KEY`를 넣으면 내 ElevenLabs 계정의 목소리가 모두 목록에 뜹니다.
  ElevenLabs 사이트의 Voice Library에서 한국어 목소리를 **My Voices**에 추가해 두면 그대로 고를 수 있습니다.
  모델은 `ELEVENLABS_MODEL`로 바꿀 수 있습니다(기본 `eleven_multilingual_v2`).

## 설치

1. **Python 3.10 이상** 설치
2. (AI 자동 원고를 쓸 때만) **Claude API 키** 준비 → `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY` 입력.
   비용을 줄이려면 `.env`에 `DROPCUT_MODEL=claude-sonnet-5-5`를 추가하세요.
3. 실행
   - Windows: `run.bat` 더블클릭
   - Mac/Linux: `./run.sh`

처음 실행할 때 필요한 패키지를 자동 설치하고 브라우저에서 `http://127.0.0.1:8000`을 엽니다.
ffmpeg는 PATH에 있으면 그것을, 없으면 `imageio-ffmpeg`에 포함된 것을 씁니다.

## 자동 모드 (클릭 없이 한 번에)

```bash
./run.sh make 영상1.mp4 영상2.mp4 --name "강아지 자동 급수기" --link "https://link.coupang.com/a/xxxx"
# 원고를 직접 쓸 때(무료): --script-file 원고.txt
# 말하는 영상: --mode talk [--cut loose|normal|tight]   상세페이지: --mode detail
# 그래픽·효과음·보정: --graphics none|few|some|many --sfx 휙 --beauty light
# 옵션: --length 15|30|45 --ratio 9:16|4:5|1:1|16:9 --style insta|classic|box|minimal --script 2 (원고 번호) --voice ko-KR-InJoonNeural --rate 15 --bgm bgm.mp3 --out output
```

`output/` 폴더에 `shorts.mp4`, `upload.txt`(제목·설명·고정댓글·원고), `subtitles.srt`가 저장됩니다.

## 꾸미기

- **글꼴**: `assets/fonts/`에 굵은 한글 글꼴(예: Pretendard Black, G마켓 산스 Bold)을 넣고
  `.env`에 `DROPCUT_FONT=글꼴 이름`을 적으면 자막·제목에 적용됩니다. 기본값은 Windows `Malgun Gothic`, Mac `Apple SD Gothic Neo`.
- **배경음악**: 저작권 걱정 없는 음원을 `assets/bgm/`에 넣으면 3단계에서 고를 수 있습니다.
- **목소리**: 기본 목소리는 Microsoft Edge 무료 TTS라 인터넷 연결이 필요합니다.

## 구조

```
dropcut/
  server.py     웹 API (FastAPI)
  pipeline.py   5단계 작업 흐름, 결과물·업로드 문구 생성
  manual.py     원고 직접 입력 해석 + 장면 자동 배치
  smartcut.py   어색한 컷 찾기(장면 전환·검은 화면·멈춘 화면)와 구간 보정
  talk.py       컷·자막 자동 편집: 말소리 구간 찾기, 받아쓰기, 군말 빼기
  graphics.py   설명 그래픽 카드(ASS 벡터 그림)
  sfx.py        효과음 만들기·섞기
  llm.py        Claude 영상 분석 + 원고 3종 + 컷 계획 (구조화 출력)
  media.py      ffmpeg: 프레임 추출, 9:16 컷 생성(가로 영상은 흐린 배경), 합치기, 최종 렌더
  subtitles.py  상단 고정 제목(흰색/노란색) + 팝 효과 자막(ASS), SRT
  tts.py        나레이션 음성 합성 (Edge 무료 / ElevenLabs)
  static/       웹 화면
```
